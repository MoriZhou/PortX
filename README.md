# PortX

> AI 原生嵌入式工程平台
>
> Define Once. Build Anywhere.

PortX 是一个面向未来的嵌入式软件工程框架，通过规范、架构与规则驱动开发流程。

PortX 的目标不是让 AI 替代工程师，而是建立一套人类工程师与 AI Agent 共同遵循的工程体系。

## 愿景

传统开发模式：

```text
需求
 ↓
工程师理解
 ↓
编写代码
 ↓
测试
```

PortX 开发模式：

```text
需求
 ↓
规范
 ↓
架构规则
 ↓
验证规则
 ↓
代码生成
 ↓
自动验证
 ↓
部署
```

无论代码来自：

- 人类工程师
- Copilot
- Claude
- Cursor
- AI Agent

都必须遵循同一套工程规则。

## 核心理念

### 规范先于代码

代码只是实现。

规范才是真正的系统定义。

### 规则先于提示词

PortX 依靠：

```text
规范
+
架构
+
规则
+
知识库
```

驱动开发行为。

### 人类与 AI 使用同一套标准

统一标准。

统一架构。

统一流程。

## 平台架构

```text
需求层
   ↓
规范层
   ↓
架构层
   ↓
规则层
   ↓
AI Agent Harness
   ↓
代码生成层

```

## 核心模块

- Specification Language（规范语言）
- Architecture Framework（架构框架）
- Rule Engine（规则引擎）
- Knowledge Base（知识库）
- Agent Harness
- Validation Engine（验证引擎）
- Migration Engine（迁移引擎）

## MCU移植只是能力之一

PortX 不是 MCU 移植工具，而是工程平台。

支持：

- MCU 移植
- BSP 生成
- 驱动开发
- 需求生成代码
- 架构验证
- 遗留代码重构
- AUTOSAR 适配
- 文档生成

## 长期目标

构建一个以规范为中心的嵌入式工程生态。

## Mission

> 将嵌入式工程知识转化为可执行规范。

**PortX**

*From Specification To Firmware.*
